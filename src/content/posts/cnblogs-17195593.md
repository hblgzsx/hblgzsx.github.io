# L2-018 多项式A除以B

# 题目描述

这仍然是一道关于A/B的题，只不过A和B都换成了多项式。你需要计算两个多项式相除的商Q和余R，其中R的阶数必须小于B的阶数。

### 输入格式：

输入分两行，每行给出一个非零多项式，先给出A，再给出B。每行的格式如下：

```text
N e[1] c[1] ... e[N] c[N]
```

其中`N`是该多项式非零项的个数，`e[i]`是第`i`个非零项的指数，`c[i]`是第`i`个非零项的系数。各项按照指数递减的顺序给出，保证所有指数是各不相同的非负整数，所有系数是非零整数，所有整数在整型范围内。

### 输出格式：

分两行先后输出商和余，输出格式与输入格式相同，输出的系数保留小数点后1位。同行数字间以1个空格分隔，行首尾不得有多余空格。注意：零多项式是一个特殊多项式，对应输出为`0 0 0.0`。但非零多项式不能输出零系数（包括舍入后为0.0）的项。在样例中，余多项式其实有常数项`-1/27`，但因其舍入后为0.0，故不输出。

### 输入样例：

```text
4 4 1 2 -3 1 -1 0 -1
3 2 3 1 -2 0 1
```

### 输出样例：

```text
3 2 0.3 1 0.2 0 -1.0
1 1 -3.1
```

- 模拟该过程，需要得到余数和商
- 余数很好说，直接是原始多项式除不尽时剩下的多项式就是余项
- 对于商需要单独开一个数组模拟
- 模拟多项式，需要考虑两项---系数和指数，指数很简单直接利用下标，而系数直接为该数组指数下标下的值。
- 注意模拟的过程中，计算商也很简单，就是将原始多项式最大下标或者最大指数代表的系数除以除数的最大小标（或者最大指数 ,前后两个最大下标不是相同的，看上面图的模拟就明白了）。
- 还有一个0.1的精度需要控制，很简单，x + 0.05 > 0.1即可。

# 提交代码

```cpp
// Problem: L2-018 多项式A除以B
// Contest: PTA
// URL: https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805060372905984
// Memory Limit: 64 MB
// Time Limit: 400 ms
// 
// Powered by CP Editor (https://cpeditor.org)

#include<bits/stdc++.h>
#define INF 0x3f3f3f3f
using namespace std;
const int N = 1e5 + 10;
vector<double> A(N), B(N), R(N);
int n, m;
int AIndex = -INF, BIndex = -INF;

void figure(vector<double> q, int x)
{
	int n = 0;
	for(int i =0; i <= x; i++)
	{
		if(abs(q[i]) + 0.05 >= 0.1) n++;
	}
	cout << n;
	if(!n)
	{
		cout << " 0 0.0\n";
		return;
	}
	
	for(int i = x; ~i; i--)
	{
		if(abs(q[i]) + 0.05 >= 0.1)
		{
			cout << " " << i << " "<< fixed << setprecision(1) << q[i];
		}
	}
	cout << "\n";
}

int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	
	int e;
	double c;
	
	cin >> n;
	for(int i = 0; i < n; i++)
	{
		cin >> e >> c;
		A[e] = c;
		if(AIndex < e) AIndex = e;
	}
	cin >> m;
	for(int i = 0; i < m; i++)
	{
		cin >> e >> c;
		B[e] = c;
		if(BIndex < e) BIndex = e;
	}
	
	int maxIndex = AIndex - BIndex;
	
	while(AIndex >= BIndex)
	{
		double c = A[AIndex] / B[BIndex];
		int e = AIndex - BIndex;
		R[e] = c;
		for(int i = AIndex, j = BIndex; ~i && ~j; i--, j--)
		{
			A[i] -= B[j] * c;
		}
		while(!A[AIndex]) AIndex--;
	}
	
	figure(R,maxIndex);
	figure(A,AIndex);
	return 0;
}
```
