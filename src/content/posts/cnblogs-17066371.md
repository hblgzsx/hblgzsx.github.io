- 强调

```
1.在进行新增，删除，修改时，一定要记得commit(),不然数据库没有数据。
eg1
sql = "update admin set mobile =%s where id=%s"
cursor.execute(sql,["18888888888",4,])
conn.commit()

2.在查询时，不需要commit(),执行fetchall/fetchone
cursor.execute("……")
#fetchone() 只能获取满足条件的第一个
```
