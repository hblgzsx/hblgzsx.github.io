# L2-013 红色警告

# 题目描述

战争中保持各个城市间的连通性非常重要。本题要求你编写一个报警程序，当失去一个城市导致国家被分裂为多个无法连通的区域时，就发出红色警报。注意：若该国本来就不完全连通，是分裂的k个区域，而失去一个城市并不改变其他城市之间的连通性，则不要发出警报。

### 输入格式：

输入在第一行给出两个整数`N`（0 < `N` ≤ 500）和`M`（≤ 5000），分别为城市个数（于是默认城市从0到`N`-1编号）和连接两城市的通路条数。随后`M`行，每行给出一条通路所连接的两个城市的编号，其间以1个空格分隔。在城市信息之后给出被攻占的信息，即一个正整数`K`和随后的`K`个被攻占的城市的编号。

注意：输入保证给出的被攻占的城市编号都是合法的且无重复，。但并不保证给出的通路没有重复。

### 输出格式：

对每个被攻占的城市，如果它会改变整个国家的连通性，则输出`Red Alert: City k is lost!`，其中`k`是该城市的编号；否则只输出`City k is lost.`即可。如果该国失去了最后一个城市，则增加一行输出`Game Over.`。

### 输入样例：

```text
5 4
0 1
1 3
3 0
0 4
5
1 2 0 4 3
```

### 输出样例：

```text
City 1 is lost.
City 2 is lost.
Red Alert: City 0 is lost!
City 4 is lost.
City 3 is lost.
Game Over.
```

> 代码长度限制 16 KB
> 时间限制 400 ms
> 内存限制 64 MB

# 思路点拨

- 并查集逆向考虑
- 正向删除边 ，反向加边
- 考虑正向的思路，当删除某一点的时候，红色警报的时候，会使之前的连通块+1，所以逆向考虑时，当增加这个点时，就会有多个点并进来。对于不是红色警报，都只会有一个点或者没有点并进来。

# 提交代码

```cpp
// Problem: L2-013 红色警报
// Contest: PTA
// URL: https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805063963230208
// Memory Limit: 64 MB
// Time Limit: 400 ms
// 
// Powered by CP Editor (https://cpeditor.org)

#include<iostream>
#include<vector>
#include<numeric>
using namespace std;
const int N = 1e5 + 10;
int n, m, k;
bool vis[N], st[N];
int d[N];
vector<int> e[N];
struct DSU
{
	vector<int> f, siz, edge;
	DSU(int n):f(n),siz(n, 1), edge(n) {iota(f.begin(), f.end(), 0);}
	int leader (int x)
	{
		while(x != f[x]) x = f[x] = f[f[x]];
		return x;
	}
	
	bool same(int u, int v)
	{
		return leader(u) == leader(v);
	}
	
	bool merge(int u, int v)
	{
		u = leader(u);
		v = leader(v);
		if(u == v) return false;
		f[u] = v;
		siz[v] += siz[u];
		edge[v] += edge[u];
		edge[v]++;
		return true;
	}
	
	bool size(int u)
	{
		return siz[leader(u)];
	}
};

int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	
	cin >> n >> m;
	for(int i = 0; i < m; i++)
	{
		int u, v;
		cin >> u >> v;
		e[u].push_back(v);
		e[v].push_back(u);
	}
	DSU dsu(n + 1);
	cin >> k;
	for(int i = 1; i <= k; i++)
	{
		cin >> d[i];
		vis[d[i]] = 1;
	}
	
	for(int i = 0; i < n; i++)
	{
		if(!vis[i])
		{
			for(int j = 0; j < e[i].size(); j++)
			{
				int v = e[i][j];
				if(!vis[v])
				{
					dsu.merge(i, v);
				}
			}
		}
	}
	
	for(int i = k; i; i--)
	{
		int cnt = 0;
		int u = d[i];
		vis[u] = 0;
		for(int j = 0; j < e[u].size(); j++)
		{
			int v = e[u][j];
			if(vis[v]) continue;
			if(!dsu.merge(u, v))
			{
				continue;
			}
			cnt++;
		}
		if(cnt > 1) st[u] = 1;
	}
	
	for(int i = 1; i <= k; i++)
	{
		if(st[d[i]]) cout << "Red Alert: City " << d[i] << " is lost!\n";
		else cout << "City " << d[i] << " is lost.\n";
	}
	
	if(k == n) cout << "Game Over.\n";
	return 0;
}
```
