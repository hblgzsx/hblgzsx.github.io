# A.小沙的好客

## 题目描述

小沙非常好客，小沙有一家超市，超市里面有为 n 件商品，小沙有 Q 个问题，小沙想问问你，如果小沙想要让你挑选最多 k个价值不大于 x 的商品，请问你能挑选的价值和最大为多少。

### 输入描述:

第一行输入两个整数 1≤n≤$10^5$，1≤Q≤$10^5$，代表商品的个数以及询问的次数。

第二行输入 n 个数字，代表商品价格序列 a ，$1 \le a_i \le 10^9$ 

随后 Q 行，每行两个正整数$1 \le k \le n$ ，$1 \le x \le 10^9$ 。

### 输出描述:

每次询问输出一行整数代表答案，共 Q 行。              

### 输入

```
5 3
1 3 3 5 10
4 3
2 3
3 10
```

### 输出

```
7
6
18
```

## 思路点拨

- 注意：二分一定要保证序列是单调的，所以需要排序

- 萌新思路： 二分+前缀和

- 大佬思路：前缀和+STL

- _lower_bound( begin,end,num)_：从数组的begin位置到end-1位置二分查找第一个大于或等于num的数字，找到返回该数字的地址，不存在则返回end。通过返回的地址减去起始地址begin,得到找到数字在数组中的下标。

  _upper_bound( begin,end,num)_：从数组的begin位置到end-1位置二分查找第一个大于num的数字，找到返回该数字的地址，不存在则返回end。通过返回的地址减去起始地址begin,得到找到数字在数组中的下标

## 提交代码

- 萌新思路

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N=1e5+10;
int a[N];
long long sum[N];
int n, m;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m;
    for(int i = 1; i <= n; i++)
    {
        cin >> a[i];
    }
    sort(a + 1, a + n + 1);
    for(int i = 1; i <= n; i++) sum[i] = sum[i - 1] + 1ll * a[i];
    while(m--)
    {
        int k, x;
        cin >> k >> x;
        int l = 0, r = n + 1;
        while(l + 1 < r)
        {
            int mid =(l + r) >> 1;
            if(a[mid] > x) r = mid;
            else l = mid;
        }
        
        cout << sum[l] - sum[max(0, l - k)] << "\n";
        
    }
    return 0;
}
```

- 大佬代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using i64 = long long;
int n, m;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cin >> n >> m;
    vector<int> a(n);
    for(int i = 0; i < n; i++)
    {
        int x;
        cin >> a[i];
    }
    sort(a.begin(), a.end());
    vector<i64> sum(n + 1);
    for(int i = 1; i <= n; i++) sum[i] = sum[i - 1] + 1ll * a[i - 1];
    while(m--)
    {
        int k, x;
        cin >> k >> x;
        
        int j = upper_bound(a.begin(), a.end(), x) - a.begin();
        cout << sum[j] - sum[max(0, j - k)] << "\n";
        
    }
    return 0;
}
```
