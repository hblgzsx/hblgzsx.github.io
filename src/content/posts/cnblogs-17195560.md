# L2-014 列车调度

# 题目描述

火车站的列车调度铁轨的结构如下图所示。

![Image.jpeg](/images/cnblogs/454d73c7a80f93c14244.jpg)

两端分别是一条入口（Entrance）轨道和一条出口（Exit）轨道，它们之间有`N`条平行的轨道。每趟列车从入口可以选择任意一条轨道进入，最后从出口离开。在图中有9趟列车，在入口处按照{8，4，2，5，3，9，1，6，7}的顺序排队等待进入。如果要求它们必须按序号递减的顺序从出口离开，则至少需要多少条平行铁轨用于调度？

### 输入格式：

输入第一行给出一个整数`N` (2 ≤ `N` ≤$10 ^ 5$)，下一行给出从1到`N`的整数序号的一个重排列。数字间以空格分隔。

### 输出格式：

在一行中输出可以将输入的列车按序号递减的顺序调离所需要的最少的铁轨条数。

### 输入样例：

```text
9
8 4 2 5 3 9 1 6 7
```

### 输出样例：

```text
4
```

> 代码长度限制 16 KB
> 时间限制 300 ms
> 内存限制 64 MB

# 思路点拨

- 首先你要读懂题意，一条隧道可以装下很多辆火车，可以停在隧道里不出去。
- 然后贪心考虑，肯定是按顺序递减进去，可以一条隧道容纳下，但是一旦后面有大的就必须新开一个隧道，所以后面进来的必须比所有开创的隧道的末尾火车序号都大，才可能新开一个隧道，所以贪心考虑就是每次放进的火车如果并不是比所有开创的隧道的末尾火车序号都大，那么就可能插到一个距离末尾序号最近的火车隧道，所以就会有一个火车隧道只要存储末尾最小的序号就行，由于需要插到一个距离末尾序号最近的火车隧道，利用二分就可以，然后对于已经开创的隧道满足一个性质，一定是最新开创的隧道的末尾火车序号最大，所以每次新序号插进来，直接可以和当前最新开创的隧道的末尾火车序号比较。

# 提交代码

```cpp
// Problem: L2-014 列车调度
// Contest: PTA
// URL: https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805063166312448
// Memory Limit: 64 MB
// Time Limit: 300 ms
// 
// Powered by CP Editor (https://cpeditor.org)

#include<bits/stdc++.h>
using namespace std;
const int N = 1e5 + 10;
int train[N], ans, n;
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	cin >> n;
	for(int i = 0; i < n; i++)
	{
		int x;
		cin >> x;
		if(train[ans] < x) train[++ans] = x;
		else
		{
			int l = 0, r = ans + 1;
			while(l + 1 < r)
			{
				int mid = (l + r) >> 1;
				if(train[mid] >= x) r = mid;
				else l = mid;
			}
			train[r] = x;
		}
		
	}
	cout << ans <<"\n";
	
	return 0;
}
