# L2-016 愿天下有情人都是失散多年的兄妹

# 题目描述

呵呵。大家都知道五服以内不得通婚，即两个人最近的共同祖先如果在五代以内（即本人、父母、祖父母、曾祖父母、高祖父母）则不可通婚。本题就请你帮助一对有情人判断一下，他们究竟是否可以成婚？

### 输入格式：

输入第一行给出一个正整数`N`（2 ≤ `N` ≤$10^4$随后`N`行，每行按以下格式给出一个人的信息：

```text
本人ID 性别 父亲ID 母亲ID
```

其中`ID`是5位数字，每人不同；性别`M`代表男性、`F`代表女性。如果某人的父亲或母亲已经不可考，则相应的`ID`位置上标记为`-1`。

接下来给出一个正整数`K`，随后`K`行，每行给出一对有情人的`ID`，其间以空格分隔。

注意：题目保证两个人是同辈，每人只有一个性别，并且血缘关系网中没有乱伦或隔辈成婚的情况。

### 输出格式：

对每一对有情人，判断他们的关系是否可以通婚：如果两人是同性，输出`Never Mind`；如果是异性并且关系出了五服，输出`Yes`；如果异性关系未出五服，输出`No`。

# 思路点拨

- 一是存储性别
- 二是利用dfs判断是否两者五代之内

# 提交代码

```cpp
// Problem: L2-016 愿天下有情人都是失散多年的兄妹
// Contest: PTA
// URL: https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805061769609216
// Memory Limit: 64 MB
// Time Limit: 200 ms
// 
// Powered by CP Editor (https://cpeditor.org)

#include<bits/stdc++.h>
using namespace std;
const int N = 1e5 + 10;
int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	int n, m, x, y;
	vector<int> e[N];
	bool flag = 0;
	char sex[N];
	bool vis[N];
	
	
	function<void (int , int)> dfs = [&](int u, int dep)
	{
		if(dep > 5) return;
		vis[u] = 1;
		for(int i = 0; i < e[u].size(); i++)
		{
			int v = e[u][i];
			if(!vis[v])
			{
				dfs(v, dep + 1);
			}
			else flag = 1;
		}
	};
	
	cin >> n;
	int ID, Father, Mother;
	for(int i = 0; i < n; i++)
	{
		cin >> ID;
		cin >> sex[ID];
		cin >> Father >> Mother;
		if(Father != -1) e[ID].push_back(Father), sex[Father] = 'M';
		if(Mother != -1) e[ID].push_back(Mother), sex[Mother] = 'F';
	}
	
	
	cin >> m;
	while(m--)
	{
		memset(vis, 0, sizeof vis);
		cin >> x >> y;
		flag = 0;
		if(sex[x] == sex[y])
		{
			puts("Never Mind");
			continue;
		}
		
		dfs(x, 1);
		dfs(y, 1);
		if(flag) puts("No");
		else puts("Yes");
	}
	
	
	return 0;
}
```
