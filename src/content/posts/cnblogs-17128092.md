# C.小沙的不懂

# 题目描述

小沙作为著名的数学差生，今天又学不会数学了，所以想请你帮帮他。 

  小沙有两个数字 a , b ，同时他还有个下标从 0 开始数字为 0 到 9 的长度为 10 的排列 p ，在将这两个数字给你之前，他会对这两个数的每一位数进行一次  $a_i := p_{a_i}$ 操作。 

  你能帮小沙分辨出这两个数在进行 $a_i := p_{a_i}$ 之前谁大谁小吗？ 

  由于你不知道小沙手中的排列，所以你需要分辨出所有可能的情况下原来的数字a 和 b 的大小关系是否相同。 

  注：小沙原来的数字可能存在前导零。 

## 输入描述:

输入两个整数 a , b，$0\leq a , b < 10^{10^5}$。

## 输出描述:

如果在每一种情况中 a>b ，则输出">"。


如果在每一种情况中 a<b ，则输出"<"。


如果在每一种情况中 a=b，则输出"="。

否则 $a\neq b$，则输出"!"。                

## 输入

```
45 54
```

## 输出

```
!
```

# 思路点拨

- 简单思考，不存在前导0时，一定有数字数位长度长的数字大于长度短的数字。
- 所以可以确定大小的时候，一定是某一个数字长度长的大。
- 其余情况都是不可以判断大小的，但是对于 a = b除外，这种情况一定是两者相等，无论怎么映射。
- 如果a 和 b的长度相同，并且 a ! = b,一定判断不了大小。
- 考虑前导零时，对于长度长的，前面相同连续数字都可以由0映射而来，比如 p = 1023456789 ,000234映射为111234,
- 所以存在一种情况，假设a和b中长度长的为a，长度短的为b,只有当a长出b的前面的数字位都为同一个数字时，才可以由零映射而来，为什么要这样考虑，一定要谨记我们要找确定的情况，对于之前的定理没有前导零，一定成立，那么是不是存在有前导零的时候该定理也会成立，这种情况是有的
- - 讨论到这里，将a前导零的部分删去，此时a和b已经长度相等了，开始比较
  - a = b,  那么就存在一种情况，在a前面是由前导零映射来的时候，存在一种情况， a等于 b，那么结果就是！
  - 之后考虑那种必然情况，对a和b每一位进行比较，如果当前一位不相等，看b的这一位是否为刚才a前导零映射的数字，如果是，那么这一位是0，由于a的这一位和b的这一位一定不同，所以在这种情况下，一定存在a的大小大于b的大小。
  - 总结，上面都是在证明存在前导零的情况下，数字数位长度长的数字大于长度短的数字，只有上面一种情况是必然事件。
  - 举个例子，a = 111234, b = 1134,
  - 111234删掉11剩余四位
  - a=1234
  - b=1134
  - 由于a和b的第一位相同，继续比较，第二位不同，由于b的这一位和a的前导零映射的数字1相同，说明b一定小于 a。注意只有前导零的存在，会使数字数位长度长的数字大于长度短的数字的结论不成立，所以需要以上考虑确定前导零存在的条件下的必然事件。

# 提交代码

```cpp
#include<bits/stdc++.h>
using i64 = long long;


int main()
{
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);
    
    std::string a, b;
    std::cin >> a >> b;
    
    if(a == b)
    {
        std::cout << "=\n";
        return 0;
    }
    
    if(a.size() == b.size())
    {
        std::cout << "!\n";
        return 0;
    }
    char ans = '>';
    if(a.size() < b.size())
    {
        ans = '<';
        std::swap(a,b);
    }
    
    
    char leadingZero = a[0];
    
    int n = a.size(), m = b.size();
    
    for(int i = 0; i < n - m; i++)
    {
        if(a[i] != leadingZero )
        {
            std::cout << ans << "\n";
            return 0;
        }
    }
    
    a.erase(a.begin(), a.begin() + n - m);
    
    if(a == b)
    {
        std::cout << "!\n";
        return 0;
    }
    
    for(int i = 0; i < m; i++)
    {
        if(a[i] != b[i])
        {
            if(b[i] != leadingZero)
            {
                std::cout << "!\n";
                return 0;
            }
            break;
        }
    }
    
    std::cout << ans << "\n";
    return 0;
    
}
```
