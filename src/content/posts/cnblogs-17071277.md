## C-Premutation

- 题目大意

```
一个序列，元素从1到n，各不相同，给出该序列任意去除一个元素剩下序列的组合，问该序列
```

- 过题代码
- 找到所有序列中第一位中的众数即为第一位，输出这一位，然后找到所有序列中第一位不同的那一个，然后输出即可

```cpp
#include<cstdio>
using namespace std;


int a[101][101];
int main(){
	int t;scanf("%d",&t);
	while(t--){
		int k;scanf("%d",&k);
		for(int i=0;i<k;i++){
			for(int j=0;j<k-1;j++){
				scanf("%d",&a[i][j]);
			}
		}
		int c=0;
		while(a[c][0]==a[c+1][0]) c++;
		if(!c) {
			if(a[c+1][0]==a[c+2][0]) {
				printf("%d ",a[c+1][0]);
				for(int i=0;i<k-1;i++) printf("%d ",a[c][i]);
			}
			else {
				printf("%d ",a[c][0]);
				for(int i=0;i<k-1;i++) printf("%d ",a[c+1][i]);
			}

		}else{
			printf("%d ",a[c][0]);
			for(int i=0;i<k-1;i++) printf("%d ",a[c+1][i]);
		}
		puts("");

	}

	return 0;
}
```

## D-Matryoshkas

- 题目大意

```cpp
求所给序列连续的最少方案数
```

- 借鉴代码

- unique () 本身**不删除元素，只是把不重复的元素放在容器的前面部分，后面的部分保持原来的顺序**

- 返回值：返回一个迭代器，这个迭代器指向最后一个不重复元素的下一个值。

-       sort(a.begin(),a.end());
        a.erase(unique(a.begin(),a.end()),a.end());
        等同于set，set不支持下标

```cpp
#include<bits/stdc++.h>

using namespace std;

const int N=200010;

int main(){
   ios::sync_with_stdio(false);
   cin.tie(nullptr),cout.tie(nullptr);

   int T;
   cin>>T;
   while(T--){
      int n;
      cin>>n;
      vector<int> a;
      unordered_map<int,int> cnt;
      for(int i=1; i<=n; i++){
         int x;
         cin>>x;
         a.push_back(x);
         cnt[x]++;
      }
      sort(a.begin(),a.end());
      a.erase(unique(a.begin(),a.end()),a.end());
      //for(auto t:a) cout<<t<<'('<<cnt[t]<<") ";
      //cout<<'\n';

      n=a.size();

      int ans=0,lst=0;
      for(int i=0; i<n; i++){
         if(i!=0&&a[i]==a[i-1]+1){
            ans+=max(0,cnt[a[i]]-lst);
            lst=cnt[a[i]];
         }
         else{
            lst=cnt[a[i]];
            ans+=cnt[a[i]];
         }
      }

      cout<<ans<<'\n';
   }

   return 0;
}
```

```

- 提交代码

- 思路剖析：

- 引进知识：`两个数的平均值可以通过位运算获得，计算公式为：

- ```
  (a+b)/2=a&b+a^b>>1`
  ```

- 首先异或会使1和0变成1，无进位，会使1和1变成0，有进位，但是没有异或体现不出来，为了使异或体现出来，正好a和b的与操作，然后把都为1的位都可以变成1,一开始是需要进位的，但是由于是求平均值，需要除以2,所以不需要向前进一位。

- 由题意如果原式成立，那么a^b>>1=a&b。

- 不明白，x不能由连续的1构成，并且为偶数

- 需要记住，判断x是否由连续的1构成，很简单，

- ```
  x&x>>1   x& x/2
  ```
