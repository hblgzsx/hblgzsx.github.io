## Django中的模块

```
模型 Model:数据层，处理与数据相关的所有事物
视图 View:视图层，用来处理用户发出的请求
模板 Template: 模板层，通过视图函数渲染html模板，得到动态的前端页面
路由 Url:网站的入口，关联到对应的视图函数，访问网址就对应一个函数
表单 Forms:表单，用在浏览器输入数据的提交，并对这些数据进行验证
后台 Admin: Django自带的一个管理后台，对你提交的数据进行管理
配置 Settings: Django的设置配置文件
```

## Virtualenv

```
Virtualenv是一个python的学你环境库，通过它可以防止各个项目之间因为python版本的不同或者第三方库版本不同引起冲突，每个虚拟环境都是独立的，干净的。
下载： pip install virtualenv
创建虚拟环境：virtualenv -p python3 env
linux启动虚拟环境：source bin/activate
windows启动虚拟环境：找到包含python.exe的目录下，输入activate,通常在Scripts文件夹下
退出虚拟环境：deactivate
```

## Django基础命令

```
django-admin startproject 项目名：创建一个django项目
python manage.py startapp 引用名：项目中创建一个应用
python manage.py shell:进入调试代码对的调试模式
python manage.py makemigrations：数据库创建更新文件
python manage.py migrate:同步到数据库更新
python manage.py flush:清空数据库
python manage.py runserver 0.0.0.0:8000: 启动开发服务器
python manage.py 回车:可查看更多命令
```

## url中的参数

```
1. ?传参   8000:?people=xxx, 上一级路由不能由/结尾。
eg http://localhost:8000/index?name=234&age=100

urls.py
path('index', index),


views.py
def index(request):
    name = request.GET.get("name", '')
    age = request.GET.get("age", 10) # 第二个为默认值
    print(name, age)
    return HttpResponse("Hello Django!")




2. 路径传参 8000/people/xxx
eg http://127.0.0.1:8000/index1/zsx/10

urls.py
path('index1/<str:name>/<int:age>', index1),

views.py
def index1(request, name, age):
    print(name, age)
    return HttpResponse("Hello Django!")

```

## 常用的request对象方法

1. request.GET 获取url上以？形式的参数
2. request.POST 获取post提交的数据
3. request.path  ：/index， 打印路径， eg http:/127.0.0.1/index, 那么这个值就是/intex1
4. request.method 请求的方法 比如：get post
5. request.COOKIES 请求过来的cookies
6. request.user 请求的用户对象，可以通过它判断用户是否登录，并获取用户信息。
7. request.session 一个即可读又可写的类似字典的对象，表示当前会话。
8. request.META 一个标准的python字典，包含所有的HTTP首部，具体的头部信息取决于客户端和服务器。

## 内置过滤器

|    内置过滤器    |     使用方法      | 说明 |
| :--------------: | :---------------: | :--: |
|       add        | {{value\|add:10} } | 给value的值加10 |
|       date       |   {{value\|date:"Y-m-d H:i:s"} }   | 把日期格式按照规定的格式显示 |

## Jinja2模板

配置Jinja2模板

- 在app目录下，新建base_jinja2.py,填入以下内容

```python
from jinja2 import Environment
from django.contrib.staticfiles.storage import staticfiles_storage
from django.urls import reverse
from .myfilter import  test

def environment(**options):
    env = Environment(**options)
    env.globals.update({
        'static': staticfiles_storage.url,
        'url': reverse,
    })

    env.filters['test'] = test # 这个是把自定义过滤器放到环境中，自定义的过滤器从myfilter.py文件中
```

```python
from mako.lookup import TemplateLookup
from django.template import RequestContext
from django.conf import settings
from django.template.context import Context
from django.http import HttpResponse


def render_to_response(request, template, data=None):
    context_instance = RequestContext(request)
    path = settings.TEMPLATES[0]["DIRS"][0]
    lookup = TemplateLookup(
        directories=[path],
        output_encoding="utf-8",
        input_encoding="utf-8",
    )
    mako_template = lookup.get_template(template)
    if not data:
        data = {}
    if context_instance:
        context_instance.update(data)
    else:
        context_instance = Context(data)

    result = {}
    for d in context_instance:
        result.update(d)
    result["csrf_token"] = f'<input type="hidden" name="csrfmiddlewaretoken" value="{request.META.get("CSRF_COOKIE", "")}"/>'
    return HttpResponse(mako_template.render_unicode(**result))
```

```python
from django import template
from app.consts import SenstiveWord # 用的时候进行导入
import jieba
# 定义过滤器


register = template.Library()

@register.filter
def test_filter(value, args):
    return value * args


# 全局屏蔽
@register.filter
def simple_check(value):
    cut_message = jieba.lcut(value)
    check = list(set(cut_message) & set(SenstiveWord))
    # print(check)
    # print(cut_message)
    if check:
        return "该消息涉及敏感关键字，已被屏蔽"
    return value

# 单个字符屏蔽
@register.filter(name="deep_check_message")
def deep_check(value):
    cut_message = jieba.lcut(value)
    new_message = []
    for m in cut_message:
        if m in  SenstiveWord:
            new_message.append("*")
        else:
            new_message.append(m)
    if new_message:
        return ''.join(new_message)
    return value
```
