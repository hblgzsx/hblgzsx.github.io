# L.小沙的抱团hard

# 题目描述

小沙在玩一个抱团游戏，最开始有 n 个人，每次小沙有 m 条指令可以下达，对于第 iii 条指令可以花费$b_i$ 的代价，要求以 $x_i$ 人为单位抱团，每个人只能在一个团里，若一个人不属于某一个恰好 $x_i$ 个人的团则将被淘汰，抱团需要所有参与抱团的人全部同意。假设参加游戏的人都足够聪明，都希望自己不被淘汰。如果你是小沙，你最少需要花费多少的代价才能使得剩余的人数最少。 

  **每个指令都可以重复使用**。 
每次要求拥抱人数不能超过当前人数。例：剩余 5 人时不能要求 6 个人拥抱在一起。

## 输入描述:

第一行输入二个整数 n , m ，代表人数以及指令个数，$1 \le n \le 10^{5}$，$1 \le m \le 500$。

随后 m 行，每行两个整数$b_i$，$x_i$，分别代表代价以及指令的内容，$1 \le b_i \le 10^5$，$2 \le x_i \le 10^5$。

## 输出描述:

输出一个整数代表小沙最少花费的代价。                      

## 输入

```
7 3
10 2
5 3
3 4
```

## 输出

```
18
```

# 思路点拨

- $dp[i]$,$i$是指当前有多少人参加比赛。
- 状态转移方程：$dp[i] = min(dp[i], dp[k] + b[j]);$
- 其中$k$是指在$i$人参赛时，对于第$j$种方案，选择$x[j]$方案后，赛场上还剩余的人数，即$i-i\%b[j]$。
- 对于$i$，如果没有进行一次转移，则$dp[i] = 0$,表示所有方案的选择人数都大于等于$i$,此时无人可以转移到$i$,所以为0。

# 提交代码

```cpp
// Problem: 小沙の抱团 hard
// Contest: NowCoder
// URL: https://ac.nowcoder.com/acm/contest/46813/L
// Memory Limit: 524288 KB
// Time Limit: 2000 ms
// 
// Powered by CP Editor (https://cpeditor.org)

#include<bits/stdc++.h>
using namespace std;
using i64 = long long;
int main()
{
	std::ios::sync_with_stdio(false);
	std::cin.tie(nullptr);
	
	int n, m;
	std::cin >> n >> m;
	
	std::vector<int> b(m), x(m);
	
	for(int i = 0; i < m; i++)
	{
		std::cin >> b[i] >> x[i];
	}
	
	std::vector<i64> dp(n + 1, 1e18);
	
	for(int i = 1; i <= n; i++)
	{
		bool end = true;
		for(int j = 0; j < m; j++)
		{
			if(x[j] <= i)
			{
				int k = i - i % x[j];
				if(k < i)
				{
					end = false;
					dp[i] = std::min(dp[i], dp[k] + b[j]);
				}
			}
		}
		if(end) dp[i] = 0;
	}
	
	std::cout << dp[n] << "\n";
	
	return 0;
}
```
