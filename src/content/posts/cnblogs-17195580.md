# L2-015 互评成绩

# 题目描述

学生互评作业的简单规则是这样定的：每个人的作业会被`k`个同学评审，得到`k`个成绩。系统需要去掉一个最高分和一个最低分，将剩下的分数取平均，就得到这个学生的最后成绩。本题就要求你编写这个互评系统的算分模块。

### 输入格式：

输入第一行给出3个正整数`N`（3 < `N` ≤$10^4$，学生总数）、`k`（3 ≤ `k` ≤ 10，每份作业的评审数）、`M`（≤ 20，需要输出的学生数）。随后`N`行，每行给出一份作业得到的`k`个评审成绩（在区间[0, 100]内），其间以空格分隔。

### 输出格式：

按非递减顺序输出最后得分最高的`M`个成绩，保留小数点后3位。分数间有1个空格，行首尾不得有多余空格。

### 输入样例：

```text
6 5 3
88 90 85 99 60
67 60 80 76 70
90 93 96 99 99
78 65 77 70 72
88 88 88 88 88
55 55 55 55 55
```

### 输出样例：

```text
87.667 88.000 96.000
```

> 代码长度限制 16 KB
> 时间限制 300 ms
> 内存限制 64 MB

# 思路点拨

- sort排序，就是简单的模拟

# 提交代码

```cpp
// Problem: L2-015 互评成绩
// Contest: PTA
// URL: https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805062432309248
// Memory Limit: 64 MB
// Time Limit: 300 ms
// 
// Powered by CP Editor (https://cpeditor.org)

#include<bits/stdc++.h>
using namespace std;
int n, m, k;

int main()
{
	ios::sync_with_stdio(false);
	cin.tie(nullptr);
	
	cin >> n >> m >> k;
	int m1 = m - 2;
	vector<double> ave(n);
	for(int i = 0; i < n; i++)
	{
		int sum = 0;
		int maxvalue = 0;
		int minvalue = 0x3f3f3f3f;
		for(int j = 0; j < m; j++)
		{
			int score;
			cin >> score;
			if(score > maxvalue) maxvalue = score;
			if(score < minvalue) minvalue = score;
			sum += score;
		}
		sum -= maxvalue;
		sum -= minvalue;
		ave[i] = sum * 1.0 / m1;
	}
	
	sort(ave.begin(), ave.end());
	for(int i = n - k; i < n; i++)
	{
		cout << fixed << setprecision(3) << ave[i] << " \n"[i == n - 1];
	}
	return 0;
}
```
