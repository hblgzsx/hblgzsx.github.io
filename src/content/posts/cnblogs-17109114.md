## A.**L2-009** 抢红包

>  [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805066890854400)

### 题目描述

没有人没抢过红包吧…… 这里给出*N*个人之间互相发红包、抢红包的记录，请你统计一下他们抢红包的收获。

**输入格式：**

输入第一行给出一个正整数*N*（≤$10^4$），即参与发红包和抢红包的总人数，则这些人从1到*N*编号。随后*N*行，第*i*行给出编号为*i*的人发红包的记录，格式如下：

$K\quad N_1 \quad P_1 \quad \cdots \quad N_k \quad P_k$ 

其中*K*（0≤*K*≤20）是发出去的红包个数，$N_i$是抢到红包的人的编号，$P_i$（>0）是其抢到的红包金额（以分为单位）。注意：对于同一个人发出的红包，每人最多只能抢1次，不能重复抢。

**输出格式：**

按照收入金额从高到低的递减顺序输出每个人的编号和收入金额（以元为单位，输出小数点后2位）。每个人的信息占一行，两数字间有1个空格。如果收入金额有并列，则按抢到红包的个数递减输出；如果还有并列，则按个人编号递增输出。

**输入样例：**

```text
10
3 2 22 10 58 8 125
5 1 345 3 211 5 233 7 13 8 101
1 7 8800
2 1 1000 2 1000
2 4 250 10 320
6 5 11 9 22 8 33 7 44 10 55 4 2
1 3 8800
2 1 23 2 123
1 8 250
4 2 121 4 516 7 112 9 10
```

**输出样例：**

```text
1 11.63
2 3.63
8 3.63
3 2.11
7 1.69
6 -1.67
9 -2.18
10 -3.26
5 -3.26
4 -12.32
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB

> 内存限制：64 MB

### 思路点拨

- 注意比较时，尽量不让浮点数比较大小，这道题可以最后处理分到元的关系，也就是除以100。
- 自设计sort函数的比较函数cmp

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 1e4+10;
struct node
{
    int w, num, cnt;
}RP[N];

bool cmp(node a, node b)
{
    if(a.w != b.w) return a.w > b.w;
    else
    {
        if(a.cnt != b.cnt) return a.cnt > b.cnt;
        return a.num < b.num;
    }
}

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    cout << fixed << setprecision(2);
    
    int m;
    cin >> m;
    for(int i = 1; i <= m; i++)
    {
        RP[i].num = i;
        int k, n;
        int p;
        cin >> k;
        for(int j = 0; j < k; j++)
        {
            cin >> n >> p;
            RP[i].w -= p;
            RP[n].w += p;
            RP[n].cnt++;
        }
    }
    
    sort(RP+1,RP+1+m,cmp);
    
    for(int i = 1; i <= m; i++)
    {
        cout << RP[i].num << " " << RP[i].w * 1./100 << "\n";
    }
    
    return 0;
    
}
```

## B.**L2-010** 排座位

> [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805066135879680)

### 题目描述

布置宴席最微妙的事情，就是给前来参宴的各位宾客安排座位。无论如何，总不能把两个死对头排到同一张宴会桌旁！这个艰巨任务现在就交给你，对任何一对客人，请编写程序告诉主人他们是否能被安排同席。

**输入格式：**

输入第一行给出3个正整数：`N`（≤100），即前来参宴的宾客总人数，则这些人从1到`N`编号；`M`为已知两两宾客之间的关系数；`K`为查询的条数。随后`M`行，每行给出一对宾客之间的关系，格式为：`宾客1 宾客2 关系`，其中`关系`为1表示是朋友，-1表示是死对头。注意两个人不可能既是朋友又是敌人。最后`K`行，每行给出一对需要查询的宾客编号。

这里假设朋友的朋友也是朋友。但敌人的敌人并不一定就是朋友，朋友的敌人也不一定是敌人。只有单纯直接的敌对关系才是绝对不能同席的。

**输出格式：**

对每个查询输出一行结果：如果两位宾客之间是朋友，且没有敌对关系，则输出`No problem`；如果他们之间并不是朋友，但也不敌对，则输出`OK`；如果他们之间有敌对，然而也有共同的朋友，则输出`OK but...`；如果他们之间只有敌对关系，则输出`No way`。

**输入样例：**

```text
7 8 4
5 6 1
2 7 -1
1 3 1
3 4 1
6 7 -1
1 2 1
1 4 1
2 3 -1
3 4
5 7
2 3
7 2
```

**输出样例：**

```text
No problem
OK
OK but...
No way
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：150 ms
> 内存限制：64 MB

### 思路点拨

- 朋友的朋友是朋友，敌人的敌人不是朋友，所以对于朋友来说可以利用并查集
- 并查集模板是2023牛客寒假集训营借鉴jiangly的代码
- 对于敌人，由于只能是两个有直接敌对关系，所以可以直接用数组去模拟敌对关系的两个人

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;
using T = double;
const int N = 105;
int em[N][N];
struct DSU
{
    vector<int> f,siz;
    DSU(int n) :f(n),siz(n){std::iota(f.begin(),f.end(),0);}
    
    int leader(int x)
    {
        while(x != f[x]) x = f[x] = f[f[x]];
        return x;
    }
    
    bool same(int a, int b)
    {
        return leader(a) == leader(b);
    }
    
    bool merge(int u, int v)
    {
        u = leader(u);
        v = leader(v);
        if(u == v) return 0;
        siz[v] += u;
        f[u] = v;
        return 1;
    }
    
    int size(int a)
    {
        return siz[leader(a)];
    }
};


int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, m, k;
    cin >> n >> m >> k;
    
    DSU dsu(n);
    
    for(int i = 0; i < m; i++)
    {
        int u, v, op;
        cin >> u >> v >> op;
        u--,v--;
        if(op == 1) dsu.merge(u,v);
        else
        {
            em[u][v] = -1; em[v][u] = -1;
        }
    }
    
    while(k--)
    {
        int a, b;
        cin >> a >> b;
        a--,b--;
        if(dsu.same(a,b) && !em[a][b]) puts("No problem");
        else if(em[a][b] && !dsu.same(a,b)) puts("No way");
        else if(!dsu.same(a,b) && !em[a][b]) puts("OK");
        else 
        {
            puts("OK but...");
        }
    }
    
    return 0;
}
```

## C.**L2-011** 玩转二叉树

> [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805065406070784)

### 题目描述

给定一棵二叉树的中序遍历和前序遍历，请你先将树做个镜面反转，再输出反转后的层序遍历的序列。所谓镜面反转，是指将所有非叶结点的左右孩子对换。这里假设键值都是互不相等的正整数。

**输入格式**

输入第一行给出一个正整数`N`(≤30)，是二叉树中结点的个数。第二行给出其中序遍历序列。第三行给出其前序遍历序列。数字间以空格分隔。

**输出格式**

在一行中输出该树反转后的层序遍历的序列。数字间以11个空格分隔，行首尾不得有多余空格。

**输入样例**

```text
7
1 2 3 4 5 6 7
4 1 3 2 6 5 7
```

**输出样例**

```text
4 6 1 7 5 3 2
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：400 ms
> 内存限制：64 MB



### 思路点拨

- 熟悉二叉树中序和先序遍历推导后序遍历
- 以下思路来源:[Potrem](https://www.cnblogs.com/Potrem/p/L2_011.html)
- 先序遍历：根→左→右
- 中序遍历：左→根→右

根据先序遍历和中序遍历，可以知道：

**1.**先序遍历的第一个值，一定是根节点；

**2.**此根节点在中序遍历中，将左右子树划分开来；

**3.**在左右子树中，于是再重复**1.2.**的过程即可；

**4.**需要注意的是，题目要求输出镜像的层序遍历，所以在DFS中，可以先DFS右子树，然后DFS左子树即可；

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;



int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    vector<int> D[35];
    int  maxdep = 0, n, Cen[35],Bef[35];
    
    cin >> n;
    for(int i = 1; i <= n; i++) cin >> Cen[i];
    for(int i = 1; i <= n; i++) cin >> Bef[i];
    
    function <void(int, int , int ,int , int , int)> dfs = [&](int o, int BL, int BR, int CL, int CR, int dep)
    {
        if(CL > CR || BL > BR) return ;
        maxdep = max(dep,maxdep);
        
        D[dep].push_back(o);
        if(CL == CR || BL == BR) return;//注意这里一定不要动，不要和之前那个合并，到了叶子节点也需要把该深度的叶子节点存入。
        int cen;
        for(cen = CL; cen <= CR; cen++) if(Cen[cen] == o) break;
        
        int Lsize = cen - CL,Rsize = CR - cen;//左右子树的下标范围
        
        if(Rsize) dfs(Bef[BR - Rsize + 1],BR - Rsize + 1,BR,cen+1,CR,dep + 1);
        if(Lsize) dfs(Bef[BL + 1],BL + 1, BL + Lsize ,CL, CL + Lsize - 1,dep + 1);
    };
    
    dfs(Bef[1], 1, n, 1, n, 1);
    int flag = 0;
    for(int i = 1; i <= maxdep; i++)
    {
        for(int j = 0; j < D[i].size(); j++)
        {
            if(flag && n != 1) cout << " ";
            cout << D[i][j];
            flag = 1;
        }
    }

    return 0;
}


```

## D.**L2-005** 集合相似度
> [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805070149828608)

### 题目描述

给定两个整数集合，它们的相似度定义为：Nc/Nt×100%。其中Nc是两个集合都有的不相等整数的个数，Nt是两个集合一共有的不相等整数的个数。你的任务就是计算任意一对给定集合的相似度。

**输入格式**

输入第一行给出一个正整数N（⩽50），是集合的个数。随后N行，每行对应一个集合。每个集合首先给出一个正整数M（⩽$10^4$），是集合中元素的个数；然后跟M个[0,109]区间内的整数。

之后一行给出一个正整数K（⩽2000），随后K行，每行对应一对需要计算相似度的集合的编号（集合从1到N编号）。数字间以空格分隔。

**输出格式**

对每一对需要计算的集合，在一行中输出它们的相似度，为保留小数点后2位的百分比数字。

**输入样例**

```text
3
3 99 87 101
4 87 101 5 87
7 99 101 18 5 135 18 99
2
1 2
1 3
```

**输出样例**

```text
50.00%
33.33%
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：400 ms
> 内存限制：64 MB

### 思路点拨

> 思路来源：[Potrem思路跳转](https://www.cnblogs.com/Potrem/p/L2_005.html)

**1.**发现集合内元素范围为[0,109]，包含重复元素，并且重复元素本身不做出贡献，故考虑使用STL中的`set`集合；

**2.**由于N很小，甚至N∗N<K，故考虑直接预处理每两个集合之间的相似度；

**3.**对于Nc，即为两个`set`集合都有的元素个数；对于Nt，即为两个`set`集合总共的元素个数；

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 55;
int n, k;
double ans[N][N];

set<int> s[N];

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    function <double(int,int)> figure=[&](int x,int y)
    {
        double Nc = 0, Nt = s[y].size();
        for(auto it = s[x].begin(); it != s[x].end(); it++)
        {
            if(s[y].find(*it) == s[y].end()) Nt++;
            else Nc++;
        }
        return Nc/Nt*100.0;
        
    };
    
    cin >> n;
    for(int m, i = 1; i <= n; i++)
    {
        cin >> m;
        for(int x, j = 1; j <= m; j++)
        {
            cin >> x;
            s[i].insert(x);
        }
    }
    
    
    for(int i = 1; i < n; i++)
    {
        for(int j = i + 1; j <= n; j++)
        {
            ans[i][j] = ans[j][i] = figure(i,j);
        }
    }
    cin >> k;
    while(k--)
    {
        int x, y;
        cin >> x >> y;
        cout << fixed << setprecision(2) << ans[x][y] << "%\n";
    }
    
    return 0;
}
```

## E.**L2-006** 树的遍历

> [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805069361299456)

### 题目描述 

给定一棵二叉树的后序遍历和中序遍历，请你输出其层序遍历的序列。这里假设键值都是互不相等的正整数。

**输入格式**

输入第一行给出一个正整数N（≤30），是二叉树中结点的个数。第二行给出其后序遍历序列。第三行给出其中序遍历序列。数字间以空格分隔。

**输出格式**

在一行中输出该树的层序遍历的序列。数字间以1个空格分隔，行首尾不得有多余空格。

**输入样例**

```text
7
2 3 1 5 7 6 4
1 2 3 4 5 6 7
```

**输出样例**

```text
4 1 6 3 5 7 2
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：400 ms
> 内存限制：64 MB

### 思路点拨

- dfs二叉树遍历，控制好下标范围

- 层序遍历，先dfs左边，后dfs右边

-     if(Lsize) dfs(A[AL + Lsize - 1],AL, AL + Lsize - 1, CL, Co - 1, dep + 1);
      if(Rsize) dfs(A[AR - 1],AR - Rsize, AR - 1, Co + 1, CR, dep + 1 );

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 50;
int n;
vector<int> A(N),C(N),D[N+1];
int maxdep;

void dfs(int o, int AL, int AR, int CL, int CR, int dep)
{
    if(AL > AR || CL > CR) return;
    maxdep = max(maxdep,dep);
    D[dep].push_back(o);
    if(AL == AR || CL == CR) return;
    int Co;
    for(Co = CL; Co <= CR; Co++) if(C[Co] == o) break;
    int Lsize = Co - CL, Rsize = CR - Co;
    if(Lsize) dfs(A[AL + Lsize - 1],AL, AL + Lsize - 1, CL, Co - 1, dep + 1);
    if(Rsize) dfs(A[AR - 1],AR - Rsize, AR - 1, Co + 1, CR, dep + 1 );
    
}



int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n;
    cin >> n;

    
    for(int i = 1; i <= n; i++) cin >> A[i];
    for(int i = 1; i <= n; i++) cin >> C[i];
    
    
    
    dfs(A[n], 1, n, 1, n, 1);
    
    int flag = 0;
    for(int i = 1; i <= maxdep; i++)
    {
        for(int j = 0; j < D[i].size(); j++)
        {
            if(flag && n != 1) cout << " ";
            cout << D[i][j];
            flag = 1;
        }
    }


    return 0;
}
```

## F.L2-007 家庭房产

> [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805068539215872)

### 题目描述

给定每个人的家庭成员和其自己名下的房产，请你统计出每个家庭的人口数、人均房产面积及房产套数。

**输入格式**

输入第一行给出一个正整数N(≤1000)，随后N行，每行按下列格式给出一个人的房产：

```text
编号 父 母 k 孩子1 ... 孩子k 房产套数 总面积
```

其中`编号`是每个人独有的一个44位数的编号；`父`和`母`分别是该编号对应的这个人的父母的编号（如果已经过世，则显示`-1`）；`k`（0≤`k`≤5）是该人的子女的个数；`孩子i`是其子女的编号。

**输出格式**

首先在第一行输出家庭个数（所有有亲属关系的人都属于同一个家庭）。随后按下列格式输出每个家庭的信息：

```text
家庭成员的最小编号 家庭人口数 人均房产套数 人均房产面积
```

其中人均值要求保留小数点后33位。家庭信息首先按人均面积降序输出，若有并列，则按成员编号的升序输出。

**输入样例**

```text
10
6666 5551 5552 1 7777 1 100
1234 5678 9012 1 0002 2 300
8888 -1 -1 0 1 1000
2468 0001 0004 1 2222 1 500
7777 6666 -1 0 2 300
3721 -1 -1 1 2333 2 150
9012 -1 -1 3 1236 1235 1234 1 100
1235 5678 9012 0 1 50
2222 1236 2468 2 6661 6662 1 300
2333 -1 3721 3 6661 6662 6663 1 100
```

**输出样例**

```text
3
8888 1 1.000 1000.000
0001 15 0.600 100.000
5551 4 0.750 100.000
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：400 ms
> 内存限制：64 MB

### 思路点拨

- 并查集，一是要控制-1 的不能合并，二是一定要使根节点是最小的。
- 注意printf("%04d"),格式化输入，输出四位数字，不足时前面补0，如果用了printf一定不要cin，cout，否则不能accept。

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;

struct home
{
    int i,cnt;
    double Num,Area;
};
const int N = 1e4+10;
vector<home> ans;
int n, k, Area[N], Num[N];
vector<int> Member(N,1);
bool vis[N];
bool cmp (home a, home b)
{
    if(abs(a.Area - b.Area) > 1e-5)
    {
        return a.Area > b.Area;
    }
    else 
    {
        return a.i < b.i;
    }
}


struct DSU
{
    vector<int> f,siz;
    DSU(int n) :f(n),siz(n, 1){iota(f.begin(),f.end(),0);}
    int leader(int x)
    {
        while(x != f[x]) x = f[x] = f[f[x]];
        return x;
    }
    
    bool same(int a, int b)
    {
        return leader(a) == leader(b);
    }
    
    bool merge(int u, int v)
    {
        if(u == -1 || v == -1) return 0;
        u = leader(u);
        v = leader(v);
        if( u == v) return 0;
        if(v > u) swap(v, u);
        siz[v] += siz[u];
        f[u] = v;
        Member[v] += Member[u];
        Num[v] += Num[u];
        Area[v] += Area[u];
        return 1;
    }
    
    int size(int x)
    {
        return siz[leader(x)];
    }
};



int main()
{
    scanf("%d",&n);
    DSU dsu(N);
    for(int i = 0; i < n; i++)
    {
        int self, Father, Mother; 
        scanf("%d %d %d",&self, &Father, &Mother);
        vis[self] = vis[Father] = vis[Mother] = 1;
        dsu.merge(self, Father);
        dsu.merge(self, Mother);
        scanf("%d",&k);
        while(k--)
        {
            int child;
            scanf("%d",&child);
            vis[child] = 1;
            dsu.merge(self, child);
        }
        int number,sumArea;
        scanf("%d %d", &number, &sumArea);
        Num[dsu.leader(self)] += number;
        Area[dsu.f[self]] += sumArea;
        
    }
    
    for(int i = 0; i <= 9999; i++)
    {
        if(dsu.f[i] == i && vis[i])
        {
            ans.push_back({i,Member[i], (Num[i] * 1.0)/(Member[i]* 1.0), (Area[i] * 1.0)/(Member[i] * 1.0)});
        }
    }
    
    sort(ans.begin(), ans.end(), cmp);
    
    printf("%d\n",ans.size());
    
    for(int i = 0; i < ans.size();i++)
    {
        printf("%04d %d %.3lf %.3lf\n",ans[i].i,ans[i].cnt,ans[i].Num,ans[i].Area);	
    }
    
    return 0;
    
}
```

## G.L2-008 最长对称字符串

> [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805067704549376)

### 题目描述

 	对给定的字符串，本题要求你输出最长对称子串的长度。例如，给定`Is PAT&TAP symmetric?`，最长对称子串为`s PAT&TAP s`，于是你应该输出11。

**输入格式**

输入在一行中给出长度不超过1000的非空字符串。

**输出格式**

在一行中输出最长对称子串的长度。

**输入样例**

```text
Is PAT&TAP symmetric?
```

**输出样例**

```text
11
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：200 ms
> 内存限制：64 MB

### 思路点拨

[思路来源：Potrem](https://www.cnblogs.com/Potrem/p/L2_008.html)

- **1.** 考虑到字符串的长度最大为1000，使用$O(n^2)$算法即可；

  **2.**遍历字符串，以遍历到的某个字符`s`作为中间点，则有两种情况：

  **1).**回文字符串长度为奇数，则当前字符为确定的中间点，往两边循环更新回文最大长度；

  **2).**回文字符串长度为偶数，则当前字符和下一位字符为一个中心，往两边循环更新回文最大长度；

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    string s;
    getline(cin, s);
    int n = s.size();
    int mx = 0;
    for(int i = 0; i < n; i++)
    {
        int l = i, r = i, ans = -1,res = 0;
        while(~i && r < n && s[l--] == s[r++] ) ans += 2;
        l = i, r = i + 1;
        while(~i && r < n && s[l--] == s[r++] ) res += 2;
        if(ans > res) swap(ans,res);
        mx = max(mx,res);
    }
    
    cout << mx << "\n";
    return 0;
}
```

## H.L2-003 月饼

> [题目跳转](https://pintia.cn/problem-sets/994805046380707840/exam/problems/994805071789801472)

### 题目描述

月饼是中国人在中秋佳节时吃的一种传统食品，不同地区有许多不同风味的月饼。现给定所有种类月饼的库存量、总售价、以及市场的最大需求量，请你计算可以获得的最大收益是多少。

注意：销售时允许取出一部分库存。样例给出的情形是这样的：假如我们有 3 种月饼，其库存量分别为 18、15、10 万吨，总售价分别为 75、72、45 亿元。如果市场的最大需求量只有 20 万吨，那么我们最大收益策略应该是卖出全部 15 万吨第 2 种月饼、以及 5 万吨第 3种月饼，获得 72+45/2=94.5（亿元）。

**输入格式**

每个输入包含一个测试用例。每个测试用例先给出一个不超过 1000 的正整数 N表示月饼的种类数、以及不超过 500500（以万吨为单位）的正整数 D 表示市场最大需求量。随后一行给出 N个正数表示每种月饼的库存量（以万吨为单位）；最后一行给出 N 个正数表示每种月饼的总售价（以亿元为单位）。数字间以空格分隔。

**输出格式**

对每组测试用例，在一行中输出最大收益，以亿元为单位并精确到小数点后 2 位。

**输入样例**

```text
3 20
18 15 10
75 72 45
```

**输出样例**

```text
94.50
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：150 ms

### 思路点拨

- 贪心考虑买月饼单价最贵即可
- 利用结构体绑定v,w,并且定义结构体比较规则，单价比较即可。

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;


const int N = 1005;
struct mooncake
{
    double v, w;
    bool operator < (const mooncake& x) const
    {
        return w / v > x.w / x.v;
    }
}M[N];


int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    
    int n, d;
    double ans = 0;
    cin >> n >> d;
    for(int i = 1; i <= n; i++) cin >> M[i].v;
    for(int i = 1; i <= n; i++) cin >> M[i].w;
    sort(M+1,M+1+n);
    for(int i = 1; i <= n; i++)
    {
        if(d > M[i].v)
        {
            d -= M[i].v;
            ans += M[i].w;
        }
        else
        {
            ans += 1.0 * M[i].w / M[i].v * d;
            break;
        }
    }
    cout << fixed << setprecision(2) << ans << "\n";
    return 0;
}
```

## I.L2-004 **这是二叉搜索树吗？**

一棵二叉搜索树可被递归地定义为具有下列性质的二叉树：对于任一结点，

**输出格式**

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：400 ms
> 内存限制：64 MB

### 思路点拨

- dfs，二叉树，思路清晰，注意好遍历的下标范围，递归树的过程类比于归并排序
- 思考后序遍历的过程，和归并排序过程是一样的
- 注意语法，`ios::sync_with_stdio(false);cin.tie(nullptr);`会使puts函数的内容最后输出，如果要控制时间，最好用cout<<字符串。

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 1005;
int n, a[N],ans[N];


int main()
{
    
    function<void(int ,int, bool) > dfs = [&] (int L, int R, bool flag)
    {
        if(L > R) return ;
        int i = L + 1, j = R;
        if(!flag) 
        {
            while(i <= R && a[L] > a[i]) i++;
            while(j > L && a[L] <= a[j]) j--;
        }
        else 
        {
            while(i <= R && a[L] <= a[i]) i++;
            while(j > L && a[L] > a[j]) j--;
        }
        if(i - j != 1) return ;
        dfs(L+1, j, flag);
        dfs(i, R, flag);
        ans[++ans[0]] = a[L];
    };
    bool flag = 0;
    cin >> n;
    for(int i = 1; i <= n; i++) cin >> a[i];
    dfs(1, n, flag);
    if(ans[0] != n)
    {
        flag = 1;
        ans[0] = 0;
        dfs(1, n, flag);
    }
    
    if(ans[0] == n)
    {
        puts("YES");
        cout << ans[1];
        for(int i = 2; i <= ans[0]; i++)
        {
            cout << " "<< ans[i];
        }
    }else puts("NO");
    return 0;
}
```

## J.L2-002 链表去重

>  [题目跳转]()

### 题目描述

给定一个带整数键值的链表 L，你需要把其中绝对值重复的键值结点删掉。即对每个键值 K，只有第一个绝对值等于 K 的结点被保留。同时，所有被删除的结点须被保存在另一个链表上。例如给定 L 为 21→−15→−15→−7→1521→−15→−15→−7→15，你需要输出去重后的链表 21→−15→−721→−15→−7，还有被删除的链表 −15→15−15→15。

**输入格式**

输入在第一行给出 L的第一个结点的地址和一个正整数 N（⩽$10^5$，为结点总数）。一个结点的地址是非负的 5 位整数，空地址 NULL 用 −1 来表示。

随后 N行，每行按以下格式描述一个结点：

```text
地址 键值 下一个结点
```

其中`地址`是该结点的地址，`键值`是绝对值不超过$10^4$的整数，`下一个结点`是下个结点的地址。

**输出格式**

首先输出去重后的链表，然后输出被删除的链表。每个结点占一行，按输入的格式输出。

**输入样例**

```text
00100 5
99999 -7 87654
23854 -15 00000
87654 15 -1
00000 -15 99999
00100 21 23854
```

**输出样例**

```text
00100 21 23854
23854 -15 99999
99999 -7 -1
00000 -15 87654
87654 15 -1
```

> 作者：陈越
> 单位：浙江大学
> 代码长度限制：16 KB
> 时间限制：400 ms
> 内存限制：64 MB

### 思路点拨

- 结构体去模拟链表，一开始需要存储链表的三个值，当前地址，当前的值，当前下一个地址，后来存储答案链表的时候就不需要维护链表的下一位地址，通过下标控制，只利用ans[i].now和ans[i+1].now就可以知道前后地址。

### 提交代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 100005;

struct linklist
{
    int now, e, ne;
}List[N], ans1[N], ans2[N];

bool vis[N];
int First, n, cnt1, cnt2;


void output(linklist ans[], int cnt)
{
    for(int i = 1; i <= cnt; i++)
    {
        if(i != cnt) printf("%05d %d %05d\n", ans[i].now, ans[i].e, ans[i+1].now);
        else 
        {
            printf("%05d %d -1\n", ans[i].now, ans[i].e);
        }
    }
}

int main()
{
    scanf("%d %d", &First, &n);
    int now, e, ne;
    for(int i = 1; i <= n; i++)
    {
        scanf("%d %d %d",&now, &e, &ne);
        List[now].now = now;
        List[now].e = e;
        List[now].ne = ne;
    }
    
    for(int i = First; i != -1; i = List[i].ne)
    {
        if(!vis[abs(List[i].e)])
        {
            vis[abs(List[i].e)] = 1;
            ans1[++cnt1] = List[i];
        }
        else
        {
            ans2[++cnt2] = List[i];
        }
    }
    
    output(ans1, cnt1);
    output(ans2, cnt2);
    return 0;
}
```
